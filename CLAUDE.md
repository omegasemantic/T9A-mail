# T9AMAIL

Web email client for a HMD feature phone (Opera Mini Extreme, 2.4" screen).
Part of a larger repo (T9A) that also holds other apps. Work ONLY in mail/.

## Output constraints
- Plain HTML only. No CSS or JS dependence, short pages, simple links.
- Anything sender-controlled (from, subject, addresses, body) must go
  through html.escape() before it is put into HTML.

## Layout
- app.py: the live Bottle app (port 80). The only file that serves traffic.
- send_json.sh: reads a JSON payload and POSTs it to Resend. Only send path.
- headers.txt: generated by pager.sh on the VPS; read-only for the app.
- pager.sh, classify_mail.py, sync_cron.sh, mail_helpers.sh: mail sync pipeline.
- browser.sh, reply.sh, tmail.sh: terminal client. Not part of the web app.
- webproto/: superseded prototype. Do not edit or delete.
- Resend key lives in ~/.resendrc. Never read, print or commit it.

## Hard guards
- NEVER touch ../map, ../maps, ../drive, ~/.t9arc or ~/.resendrc.
- The /switch route and static/ticket.html must keep working. Never
  remove or rename them: they are the only way to switch apps by phone.
- Never run git clean, reset --hard, checkout ., stash, or restart/stop
  any service. Never run send_json.sh or send mail.

## Rules
- One task per session. Edit only the files named in the task.
- Do not delete files. Do not touch mail.raw, headers.txt, request.json.
- Prefer the smallest change that works. No refactors, no extra features.
- After editing app.py run: python3 -m py_compile app.py
- Show a diff summary at the end and stop. I commit.
